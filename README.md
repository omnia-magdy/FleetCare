FleetCare Pro is an enterprise-grade vehicle maintenance management system developed using ASP.NET Core MVC and Entity Framework Core. 
The application implements Code-First migrations, complex domain relationships, and a robust layered architecture. 
System security is powered by ASP.NET Core Identity, featuring role-based authorization and policy restrictions for Admins, FleetManagers, and Drivers. 
Key modules include vehicle lifecycle tracking, master-detail service logging, automated file uploads, and custom data validation. 
Advanced infrastructure features comprise custom action filters for audit logging, middleware handling, and reusable view components for real-time analytics. 
The solution is designed to deliver a secure, scalable, and fully structured backend framework for efficient fleet administration.
